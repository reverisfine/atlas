# 은또링쌤의 행성 지도 · ATLAS

특성화고 「성공적인 직업생활」(직업탐구영역 · 2027 수능 대비) **개념 마인드맵** 웹앱입니다.
가운데가 단원, 가지가 소단원, 잎이 개념입니다. 보기의 개념을 알맞은 소단원에 옮겨 붙이면
정답 표시와 함께 그 개념의 정리와 기출 선지가 열립니다.

**접속 주소** → https://reverisfine.github.io/atlas/

> 인출 암기용 앱 [행성탐사대](https://reverisfine.github.io/planet-lab/)와는 다른 앱입니다.
> 탐사대는 혼자 외우는 용도, 지도는 수업 중 화면에 띄우는 용도입니다.

---

## 파일 구성

```
atlas/
├─ index.html              홈 · 20강 전체 지도
├─ lesson01.html           01강 (강 페이지는 껍데기 10줄)
├─ manifest.json           앱 설치 정보
├─ icon.png                홈 화면 아이콘 (512×512)
├─ assets/
│  ├─ style.css            디자인 시스템 (여기만 고치면 전체 반영)
│  ├─ lessons.js           20강 목차 · 공통 셸(상단 내비게이션)
│  ├─ app.js               마인드맵·매칭·팝오버·그래프 엔진
│  └─ fonts/               Pretendard · 나눔펜 (내장 · 인터넷 없이도 동일)
└─ data/
   └─ lesson01.js          01강 학습 데이터
```

**엔진과 데이터가 분리되어 있습니다.** 강을 추가할 때 `data/lessonNN.js` 하나만 만들면 됩니다.
디자인이나 기능을 고칠 때는 `assets/` 안의 파일 하나만 고치면 20강에 모두 반영됩니다.

외부 라이브러리를 쓰지 않고, 글꼴도 저장소 안에 들어 있어 **인터넷 없이도 같은 화면**으로 열립니다.
`fetch`를 쓰지 않으므로 파일을 더블클릭해서 여는 방식으로도 동작합니다.

## 배포 방법

1. 저장소에 파일을 모두 올립니다
2. **Settings → Pages → Source**를 `main` 브랜치 / `/ (root)`로 지정합니다
3. 1~2분 뒤 위 주소로 접속됩니다

### 홈 화면에 추가하기

- **아이폰** — 사파리로 접속 → 아래 공유 버튼 → `홈 화면에 추가`
- **안드로이드** — 크롬으로 접속 → 오른쪽 위 점 세 개 → `홈 화면에 추가`

## 강 추가하는 법

### 1. 데이터 파일 만들기

`data/lesson01.js`를 복사해 `data/lesson02.js`로 만들고 내용을 바꿉니다.

```js
const LESSON={no:2, title:"생애 발달과 직업적 성공 (1)",
  sub:"보기에 흩어진 개념을 알맞은 소단원으로 옮겨 붙이세요."};

const DATA=[                       // 소단원 4개 (개수는 바꿔도 됩니다)
 {b:"소단원 이름", desc:"한 줄 설명", items:[
   {k:"개념 이름", s:3, hot:1, d:`개념 정리 HTML`}
 ]}
];

const PITS=[                       // 「이건 꼭 틀려요」
 {q:"🧩 함정 질문", a:`정리 HTML`,
  vs:[["왼쪽 제목","내용"],["오른쪽 제목","내용"]]}
];

const GICHUL=[                     // 회차별 기출 선지
 {y:"2027", e:"9월 모평", qs:[
   {n:1, pt:"3점", t:"주제", link:"개념 이름", more:["보조 개념"], a:"⑤",
    stem:"발문 요지",
    ch:[["ㄱ","o","선지 요지","근거 한 줄"],
        ["ㄴ","x","선지 요지","근거 한 줄"]]}
 ]}
];

const YEARS=[{y:'2022',n:9,su:2}, ...];   // 학년도별 문항 수 (su = 그중 수능)
const FREQ =[['개념 묶음',24], ...];        // 개념별 출제 빈도
const CNOTE=`집계 방식 설명`;
```

### 2. 강 페이지 만들기

`lesson01.html`을 복사해 `lesson02.html`로 만들고, 맨 아래 한 줄만 고칩니다.

```html
<script src="data/lesson02.js"></script>
```

### 3. 목차 열기

`assets/lessons.js`에서 해당 강의 `ready:false`를 `ready:true`로 바꿉니다.
홈 화면에서 카드가 활성화되고, 강 페이지 상단 드롭다운에도 나타납니다.

## 데이터 작성 규칙

| 항목 | 뜻 |
|---|---|
| `s` | 출제 중요도 1~3 (개념 제목 옆 점 개수) |
| `hot` | 1이면 「기출 단골」 배지 |
| `d` | 개념 정리 HTML. `<table>` `<ul>` 사용 가능 |
| `link` | 기출 문항이 붙을 개념 이름 (`DATA`의 `k`와 정확히 일치해야 함) |
| `more` | 문항이 여러 개념에 걸칠 때 보조 개념 (「선지 일부」 배지가 붙음) |
| `ch` | `[보기기호, o/x/-, 선지 요지, 근거]` |

`d` 안에서 쓸 수 있는 표시입니다.

- `<b>` 굵게 · `<span class="key">` 분홍 강조 · `<span class="hl">` 형광펜
- `<div class="note">` 노란 보충 상자
- `<div class="srcline">교재 서술은 여기까지입니다</div>` 교재 내용과 보충 내용을 가르는 구분선

## 근거 표기 원칙

- 법령이 걸린 내용은 **조문을 직접 확인한 뒤** 조문 번호를 적습니다
- 교재 본문에 없는 보충 내용은 `srcline`으로 구분하고 출처를 밝힙니다
- 기출 선지는 원문 그대로가 아니라 **요지로 줄여** 적습니다
- 시험지에 텍스트 정보가 없어 이미지 판독(OCR)으로 확인한 회차는 그 사실을 카드에 표시합니다
